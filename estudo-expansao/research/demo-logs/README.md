Respostas geradas pela comparação ao vivo do NexoHansen (`rag-study serve`, D41). Cada arquivo `live-<AAAAMMDDTHHMMSSZ>[-dryrun].jsonl` corresponde a uma sessão do serviço, no mesmo formato de registro do `raw.jsonl`.
